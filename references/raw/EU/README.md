# EU — Europaparlamentets nivå

Källdokument från EU-nivån: EP-gruppen Gröna/EFA, MEP-positioner, EP-resolutioner.

**Primära användningsområden:** Klimat, biodiversitet, handelspolitik, migration, energiunion.

**OBS:** EU-nivån är ett parallellt auktoritetsspår — inte direkt överordnad riksnivå.
Vid citering ska alltid kopplingen till riksnivån göras explicit.

## Namnkonvention
```
EP-resolution YYYY-MM-DD [Ämne].md
MEP-uttalande [Namn] YYYY [Ämne].md
Gröna-EFA position YYYY [Ämne].md
```
