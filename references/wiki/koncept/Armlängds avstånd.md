# Armlängds avstånd

**Senast uppdaterad:** 2026-05-02
**Huvudkällor:** 
- [[Kulturpolitiskt program 2018]] (Rank 2)
- [[Partiprogram 2025]] (Rank 1)

## Definition
Principen om **armlängds avstånd** innebär att politiker ska besluta om ramar och resurser för kultur och media, men aldrig styra det konstnärliga innehållet eller den journalistiska gärningen.

## Tillämpning
- **Konstnärlig frihet:** Skydda kulturen från politisk påverkan och kortsiktiga kommersiella intressen. [[mp-ai-wiki/references/raw/kongress/kulturpolitiskt-program.md#Frihet|Kulturpolitiskt program 2018]]
- **Oberoende media:** Värna public service oberoende och stärka stödet till den lokala journalistiken. [[mp-ai-wiki/references/raw/program/miljopartiets-partiprogram-2025.md#8. Ett fritt blomstrande kulturliv och ett starkt civilsamhälle|kap 8.1]]
- **Museer:** Museernas roll som självständiga kunskapsinstitutioner ska säkras genom lagstiftning. [[mp-ai-wiki/references/raw/kongress/kulturpolitiskt-program.md#Kulturarv|Kulturpolitiskt program 2018]]
